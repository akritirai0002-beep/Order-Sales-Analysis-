# 📦 Northwind Order & Sales Analysis Dashboard

An end-to-end sales and order intelligence project built using the relational Northwind database schema. This analysis evaluates revenue trends, fulfillment timelines, product order volume, and freight dynamics.

The repository includes normalized transaction data, analytical solution write-ups, problem statements, and an interactive **Power BI** report (`.pbix`).

---

## 📌 Project Overview

Efficient order processing and sales visibility are essential for modern supply chain and revenue optimization. 

This project evaluates:
- **Sales Revenue & Volume:** Tracking gross sales, discounted values, and net revenue across historical order records.
- **Order Details & Product Distribution:** Evaluating order line items, quantity demand, and pricing trends.
- **Fulfillment & Logistics:** Monitoring shipping turnaround times, freight charges, and carrier distribution.
- **Business KPI Solutions:** Resolving core evaluation questions regarding order velocity and top customer accounts.
